Pizzadonia

Muat turun aplikasi

Dua app berasingan: satu untuk pelanggan membuat tempahan, satu lagi untuk penjual mengurus tempahan. Kedua-duanya memuatkan laman produksi terkini secara langsung.

Pelanggan

Pizzadonia

Lihat menu, buat tempahan, bayar dengan DuitNow QR dan jejak status tempahan.

Versi 1.2.5 · Android 7.0+ · 5.3 MB Muat turun APK
Penjual

Pizzadonia Penjual

Terus membuka dashboard tempahan. Masukkan PIN akses untuk mula mengurus pesanan.

Versi 1.2.5 · Android 7.0+ · 5.3 MB Muat turun APK

Cara pasang

  1. Tekan butang muat turun di atas.
  2. Buka fail APK yang dimuat turun.
  3. Benarkan Install unknown apps untuk pelayar atau Files jika diminta.
  4. Tekan Install, kemudian buka app.

Nota: Jika telefon sudah ada app Pizzadonia lama dengan tanda tangan berbeza, nyahpasang app lama dahulu. Kedua-dua app ini menggunakan ID berasingan, jadi ia boleh dipasang bersama.

Kemas kini automatik: App menyemak versi baharu setiap kali dibuka. Jika ada versi lebih baharu, app memuat turun APK secara automatik dan membuka pemasang sistem. Anda hanya perlu menekan Install; Android tidak membenarkan pemasangan senyap sepenuhnya untuk app sideload. Benarkan Install unknown apps sekali sahaja untuk app ini.
